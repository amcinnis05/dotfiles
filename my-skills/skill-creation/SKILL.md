# Skill Creation

Use this skill when creating or revising an agent skill.

1. Define the specific task the skill should help an agent complete. Keep its scope focused.
2. Create a dedicated directory for the skill and put its instructions in `SKILL.md`.
3. Add YAML frontmatter with a concise `name` and a `description` that says when the skill applies.
4. Write actionable instructions, including relevant workflow steps, constraints, and tools. Avoid duplicating general agent guidance.
5. Keep examples minimal and include only details that improve task outcomes.
6. Review the skill for clarity, consistency, and whether an agent can tell when to use it.
